# WealthTrack 💰

A Python-based personal finance tracker built to manage income and expenses through a simple terminal interface.

## Features
- Add transactions
- View transaction history
- Update transactions
- Delete transactions
- Automatically generate transaction IDs
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Validate transaction amounts and types

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## Concepts Used
- Classes and Objects
- Constructors (`__init__`)
- Class and Instance Variables
- Properties and Setters
- Encapsulation
- CRUD Operations
- Loops and Conditional Statements
- Functions
- Exception Handling
- Object Attribute Management

## How to Run

```bash
python main.py
```
